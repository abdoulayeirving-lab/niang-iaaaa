# NIANG IA download page

This folder is a standalone static download page for the Windows desktop app.
It does not turn the Windows app into a web app or run the desktop assistant on
Vercel. The download button points to the latest GitHub release installer.

## Deploy to Vercel

From this directory, run `npx vercel --prod` and follow the prompts to create
and deploy a new Vercel project. Choose the **Other** framework preset and keep
the default output directory. No build command or environment variables are
required.
